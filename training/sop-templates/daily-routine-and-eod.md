# Daily routine + EOD report (setter)

Times are the team's time zone; adjust to your leads' business hours.

| Time | Block |
|---|---|
| 8:00 – 8:15 | Standup: yesterday / today / blockers |
| 8:15 – 8:45 | Call prep: new leads (last 12 h) → hot → follow-ups → revive. Read notes before dialing |
| 8:45 – 11:45 | Call block 1 (12-15 dials). Log every call in the CRM as it happens |
| 11:45 – 12:30 | CRM QA: required fields, status, notes, next task, duplicates |
| 1:30 – 2:30 | Paid learning (academy module + sandbox practice) |
| 2:30 – 4:30 | Call block 2: callbacks, next-day confirmations, revives (10-12 dials) |
| 4:30 – 5:15 | QA: grade recorded calls, check drafts waiting for approval |
| 5:15 – 5:45 | CRM hygiene + board grooming |
| 5:45 – 6:00 | EOD report |

First hour variant for setters with booked visits: log yesterday's appointments in the tracker, note each deal, ask the closer for outcomes in the appointments channel, update stage + next task + color code (negotiation, lost, financing, closed).
