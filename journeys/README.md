# Journeys

Automated follow-up journeys. Each folder is one journey you can run on its own.

| Folder | What it is |
|---|---|
| [`24-step/`](24-step/) | **24-step nurture engine**: 24 emails and 6 texts over 90 days, with the code that sends them safely (dry run by default, one message per channel per step, caps, STOP forever, circuit breaker, kill switch) |

Related: the [96-step year-round journey](../playbooks/) is a content plan (CSV/JSON) you can load into this engine or into your CRM's own workflows.
